Features

为电商美工和运营准备的工具

不用再一张张右键另存，整页商品图一次性拿到手。

整页图片提取

自动识别 img 标签、懒加载属性、srcset 与背景图，主图、详情图、SKU 图都不遗漏。

勾选后再下载

提取结果在新标签页集中展示，支持全选、反选、单张勾选，只下载真正需要的那几张。

统一转 PNG

无论原图是 JPG、WebP 还是 AVIF，全部通过 Canvas 重新编码为无损 PNG，命名自动编号。

批量并发处理

带进度条与失败清单，上百张图也能稳定跑完，单张失败不影响整体任务。

大图即时预览

双击任意缩略图即可查看原图与尺寸，确认画质后再决定是否下载。

本地运行不上传

所有图片解析与转换都在浏览器本地完成，不经过任何第三方服务器。

How it works

三步完成图片提取

打开商品页 → 点击按钮 → 勾选下载，全程不超过半分钟。

1

打开商品详情页

在淘宝、天猫、京东或拼多多打开任意商品的详情页，等待图片加载完成。

2

点击「获取图片」

页面右下角会固定显示橙色按钮，点击后自动扫描整页商品图并汇总。

3

勾选并下载

在预览页勾选需要的图片，点击下载，全部保存为 PNG 并自动按序号命名。

两分钟完成安装

插件以开发者模式本地加载，无需上架商店，也不需要注册账号。下载源码后按下面三步操作即可。

  • 1 打开 Chrome（或 Edge），地址栏输入 chrome://extensions（Edge 为 edge://extensions）并回车
  • 2 打开右上角的「开发者模式」/「开发人员模式」开关
  • 3 点击「加载已解压的扩展程序」，选择项目根目录（含 manifest.json 的那一层）
终端
# 克隆项目到本地
git clone https://github.com/<你的用户名>/dianshang-plugin.git

# 进入项目根目录（manifest.json 所在位置）
cd dianshang-plugin

# 在浏览器中加载本目录
chrome://extensions → 开发者模式 → 加载已解压的扩展程序
